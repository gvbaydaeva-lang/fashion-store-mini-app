# Изображения

Изображения в этой папке созданы для демонстрационного прототипа «Фэшн стор» с помощью встроенного OpenAI ImageGen. Они не являются фотографиями реального ассортимента магазина.

Финальные файлы сохранены как оптимизированные JPEG шириной 733–825 px. Этот формат выбран вместо WebP, потому что доступные системные конвертеры не содержат WebP-кодека; дополнительная зависимость проекту не нужна.
