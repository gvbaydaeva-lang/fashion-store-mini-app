# CLAUDE.md

## Что это

Локальный интерактивный прототип Telegram Mini App магазина «Фэшн стор» — «Стильная женская одежда на каждый день».

Прототип показывает полный путь покупателя и продавца, но не подключён к серверу, платёжной системе, боту или реальным остаткам.

## Файлы

- `index.html` — точка входа, мобильная оболочка и подключение Telegram Web App SDK.
- `styles.css` — светлая и тёмная темы, mobile-first компоновка, компоненты и анимации.
- `data.js` — бренд, товары, цвета, размеры, остатки и способы получения.
- `core.js` — тестируемая бизнес-логика фильтров, корзины, итогов и заказа.
- `app.js` — экраны, события, Telegram SDK, BackButton и локальное сохранение.
- `assets/` — локальные демонстрационные фотографии и сведения об их происхождении.
- `tests/` — автоматические проверки данных и бизнес-логики.
- `docs/superpowers/` — согласованная спецификация и план реализации.

## Навигация покупателя

Пять постоянных разделов:

1. `home` — Главная.
2. `catalog` — Каталог.
3. `cart` — Корзина.
4. `orders` — Заказы.
5. `store` — Магазин.

Внутренние экраны:

- `product` — карточка товара;
- `checkout-contact` — контакты;
- `checkout-delivery` — получение;
- `checkout-review` — проверка заказа;
- `payment-success` — результат демонстрационной оплаты;
- `order-detail` — текущий заказ.

Путь покупателя:

```text
Главная → Каталог → Товар → Корзина
→ Контакты → Получение → Проверка
→ Демо-оплата → Заказ
```

## Навигация продавца

Кнопка «Режим продавца» находится внизу раздела «Магазин».

```text
Магазин → Заказы продавца → Карточка заказа
→ Подтверждение «Заказ собран»
```

Экраны продавца:

- `seller-orders` — вкладки «Собрать» и «Готовы»;
- `seller-order` — состав заказа и изменение статуса.

В рабочей версии демонстрационная кнопка должна быть удалена. Сервер обязан проверить подпись `Telegram.WebApp.initData`, свежесть `auth_date` и Telegram ID сотрудника.

## Где менять данные

Все демонстрационные данные находятся в `data.js`.

### Магазин

Объект `STORE` содержит название, описание, адрес, график и контакты.

### Категории

Массив `CATEGORIES` содержит `id` и русское название каждой категории. Значение `all` используется для показа всего каталога.

### Товар

Обязательные поля:

- `id` — уникальный латинский идентификатор;
- `name` — название товара;
- `category` — идентификатор категории;
- `price` — текущая цена числом;
- `oldPrice` — реальная старая цена или `null`;
- `badge` — «Новинка», «Последний» или `null`;
- `images` — массив локальных путей;
- `colors` — цвета с `id`, названием и HEX-кодом;
- `description`, `composition`, `care`, `fit`, `model` — данные карточки;
- `measurements` — замеры по размерам;
- `variants` — остатки конкретных сочетаний цвет + размер.

Остаток задаётся так:

```js
{ colorId: 'blue', size: 'M', stock: 2 }
```

Нулевой остаток оставляет размер видимым, но кнопка становится отключённой и приглушённой.

### Получение

Массив `DELIVERY_METHODS` содержит самовывоз и курьера. Поле `demo: true` нельзя убирать, пока реальные процессы магазина не подтверждены.

## Как заменить изображение

1. Подготовить вертикальный JPEG шириной около 800–1000 px.
2. Положить файл в `assets/`.
3. Использовать латинское имя в нижнем регистре без пробелов.
4. В `data.js` заменить путь в массиве `images` нужного товара.
5. Запустить автоматические тесты.

## Локальное сохранение

- `fashion-store-cart-v1` — корзина.
- `fashion-store-order-v1` — текущий демонстрационный заказ.

Чтобы начать сценарий заново, очистите данные сайта в браузере или удалите эти два ключа из `localStorage`.

## Запуск

Из корня проекта:

```bash
python3 -m http.server 4173 --directory tg-app
```

Затем открыть:

```text
http://localhost:4173
```

Открытие `index.html` двойным нажатием не рекомендуется: локальный сервер точнее воспроизводит размещённый Mini App.

## Тесты

Из корня проекта:

```bash
node --test tg-app/tests/*.test.js
```

Проверка синтаксиса:

```bash
node --check tg-app/data.js
node --check tg-app/core.js
node --check tg-app/app.js
```

## Telegram Web App SDK

`index.html` подключает официальный файл:

```text
https://telegram.org/js/telegram-web-app.js
```

Приложение использует:

- `ready()` и `expand()`;
- `themeParams` и событие `themeChanged`;
- `BackButton`;
- имя из `initDataUnsafe.user` только для приветствия;
- safe areas через CSS-переменные Telegram и `env(safe-area-inset-*)`.

В обычном браузере используется безопасный fallback: имя «Гость», собственная кнопка назад и запасные цвета темы.

## Ограничения прототипа

Не реализованы:

- сервер и база данных;
- проверка подлинности `initData`;
- реальная роль продавца;
- настоящий источник товаров и остатков;
- резервирование последнего экземпляра;
- платёжный провайдер, callback и онлайн-касса;
- настоящая доставка, маршрут и возврат денег;
- уведомления Telegram-бота;
- синхронизация между разными устройствами.

Нельзя использовать этот прототип для приёма реальных заказов и оплаты без серверной части и проверки процессов магазина.
