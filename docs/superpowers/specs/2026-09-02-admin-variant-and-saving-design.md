# Варианты цвета и сохранение товара — дизайн

## Цель

Сделать форму товара понятной: каждый цвет редактируется отдельным блоком, у него свои размеры и остатки; черновики сохраняются без обязательных полей, а публикация требует только согласованный набор данных. Опубликованный товар после редактирования остаётся полноценной карточкой в списке.

## Граница задачи

Изменяются существующие vanilla JavaScript-клиент и Supabase Edge Function `admin-api`. Новые библиотеки, фреймворки, таблицы или авторизация не добавляются. Работа относится только к закрытой панели продавца; доступ к ней по-прежнему проверяет сервер.

## Модель вариантов

`Product.colors` остаётся массивом цветов, но `Product.sizes` больше не является общим списком размеров для всех цветов. Каждый вариант в `Product.variants` уже содержит `colorId`, `size`, `stock` и `enabled`; он становится единственным источником размеров конкретного цвета.

Один цвет — один объект:

```js
{
  id: 'korichnevyy-shokoladnyy',
  name: 'Коричневый, шоколадный'
}
```

Значение `name` — точный текст продавца. Запятая внутри него не создаёт второй цвет: это можно использовать для синонимов. Технический `id` создаётся без префикса `color-` и не показывается пользователю.

На экране каждый цвет отображается отдельной карточкой. В карточке есть:

- поле «Цвет / синонимы»;
- поле «Размеры этого цвета»;
- строки остатков только для введённых размеров;
- кнопка удаления цвета.

Кнопка «Добавить вариант цвета» добавляет новую пустую карточку. Она не меняет текст в уже введённом цвете. Пустая дополнительная карточка не сохраняется как цвет и не создаёт варианты.

## Синхронизация формы

Клиент собирает блоки цветов в массив `colors` и строит `variants` только из размеров данного блока. При изменении текста, размеров или порядка существующий остаток сохраняется по паре `colorId + size`, если эта пара не изменилась. Удаление цвета или размера удаляет только его варианты.

При сериализации в API каждый вариант получает `color_name` из соответствующего `Product.colors[].name`. Поэтому сервер всегда хранит и возвращает ручное название цвета, а не его технический идентификатор.

## Правила сохранения

### Черновик

Кнопка «Сохранить черновик» не запускает проверку обязательных полей. Можно сохранить товар с одним полем или без полей. Клиент отправляет пустые значения в допустимом серверном формате: цена и оптовая цена не становятся нулём, если они не введены.

### Публикация

Кнопка «Опубликовать» проверяет, что есть:

1. хотя бы одно фото;
2. название;
3. цена;
4. описание;
5. оптовая цена;
6. хотя бы один цвет;
7. хотя бы один размер у цвета;
8. хотя бы один включённый вариант с целым остатком от нуля.

Категория, артикул, старая цена и поставщик необязательны. Те же правила проверяются на сервере перед сменой статуса на `published`, чтобы публикацию нельзя было обойти запросом напрямую.

## Сохранение уже опубликованного товара

При редактировании опубликенного товара клиент не должен подменять его черновиком. Серверная операция публикации всегда возвращает товар целиком: поля, варианты и фотографии — даже если товар уже имеет статус `published`. Клиент заменяет строку списка только этим полным ответом. Поэтому карточка остаётся во вкладке «Опубликованы» с правильным названием, фото и зелёным статусом.

## Ошибки и сохранность данных

При отказе сервера форма и локальная копия черновика сохраняются. Сообщение объясняет причину и не стирает введённые поля. Ошибки обязательности показываются только после нажатия «Опубликовать»; сохранение черновика их не показывает.

## Проверка

Автоматические тесты проверяют:

- отдельные цвета с разными наборами размеров;
- сохранение ручного имени цвета и отсутствие `color-` в имени;
- обязательность описания и оптовой цены только для публикации;
- разрешённый неполный черновик;
- полный ответ API при повторной публикации опубликенного товара.

Также выполняются существующие проверки синтаксиса и полный набор Node-тестов. До заявления о Telegram-проверке изменения должны быть опубликованы и открыты в самом Mini App; локальный браузер не заменяет проверку iOS Telegram.
