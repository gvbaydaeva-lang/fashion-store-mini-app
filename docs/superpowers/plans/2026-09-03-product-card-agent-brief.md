## Задачи

### 1. Исправить группировку цветов

- Найди функцию `getProductGroup(product)` в `tg-app/app.js`.
- В группу включай все товары со статусом `published` и одинаковым `groupId`, даже если у товара нет положительного остатка.
- Не включай `draft` и `archived`.
- Сохрани отдельные `productId`, изображения, `colorId`, размеры и остатки для каждого варианта.
- Цвет без остатка должен оставаться видимым и открывать свою карточку для просмотра.
- Такой цвет нельзя добавлять в корзину или покупать.
- Не делай HTML-кнопку цвета `disabled`, иначе пользователь не сможет открыть карточку; используй понятный визуальный статус и `aria-disabled`.

### 2. Исправить связь цвета, размера и остатка

- При первом открытии выбирать первый цвет текущего товара сразу.
- При переключении цвета открывать соответствующий `productId` и сбрасывать выбранный размер.
- Для выбранного цвета показывать размеры и их статусы на основании его собственных `variants`.
- В заказ пропускать только вариант, у которого `enabled !== false` и `stock > 0`.
- Для опубликованного товара с нулевыми остатками показывать карточку, но блокировать заказ ясным сообщением.
- Не дублировать разные правила остатков в нескольких местах: вынести общую проверку в существующую чистую бизнес-логику, если это не ломает архитектуру.

### 3. Исправить мобильную компоновку

- На ширинах 320, 375 и 430 px размещать цвета ровно по три в ряд.
- Длинные названия цветов должны переноситься, не создавая горизонтальную прокрутку.
- Если размер один — он занимает всю строку.
- Если размеров два и больше — размеры идут по три в ряд.
- Уменьшить заголовок товара до согласованного размера из основного плана.
- Поднять блок «Цвет» и «Размер» ближе к описанию/цене, не меняя соседние экраны без необходимости.
- Нижняя фиксированная панель «В корзину / Купить сейчас / Перейти в корзину» не должна закрывать размер или последний ряд вариантов.
- Сохранить минимальную область нажатия 44 × 44 px, safe areas, светлую и тёмную темы.

### 4. Проверить Preview администратора

- В Preview карточки администратора должны быть видны цвета и размеры без необходимости прокручивать экран на большое расстояние.
- Preview должен отображать все выбранные цвета, включая цвета без остатка, с понятным визуальным отличием недоступных вариантов.
- Не путай Preview продавца с покупательской карточкой: проверь оба сценария отдельно.

### 5. Написать регрессионные тесты до исправления

Добавь тесты, которые сначала падают на старом поведении, затем проходят после исправления:

- доступный размер активен сразу при первом открытии карточки;
- опубликованный цвет без остатка остаётся в DOM;
- опубликованный товар без положительных остатков остаётся видимым;
- переключение на другой цвет меняет `productId`, изображение и набор вариантов;
- цвет/размер с нулевым остатком нельзя добавить в корзину;
- один размер получает класс полной ширины;
- несколько размеров используют три колонки;
- цвета на мобильной ширине используют три колонки;
- fixed actions не перекрывают последний ряд размеров;
- в коде больше нет блока «Доставка, обмен и возврат», если он уже удалён по согласованному плану.

- нет горизонтального overflow;
- нижняя панель не накрывает размеры;
